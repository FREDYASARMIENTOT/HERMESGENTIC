# Proyecto

HermesAgentic Enterprise

## Objetivo

Crear la versión Enterprise de Hermes Agent especializada en Azure Foundry.

## Arquitectura

Azure OpenAI
Azure Monitor
Log Analytics
PowerShell
Terraform
Docker
GitHub Actions

## Componentes

HermesTools
Azure Gateway
FinOps
Diagnostics
Telegram
PowerBI

## Reglas

Todo código debe estar documentado.

Todas las funciones tendrán comentarios.

Todo script deberá poder ejecutarse independientemente.

Se utilizará PowerShell 5.1 y PowerShell 7.

El repositorio será completamente modular.
